## How to Run

### 1. Client
```
cd client
npm install
npm run dev
```

### 2. Server
```
cd server
npm install
npm start
```

### 3. Environment variables
Create a file named `.env` inside the `server` folder and add your own keys:

```
STRIPE_SECRET_KEY=your_key_here
```
